6. Revised Task 12 Design Challenge Architecture (Strategy Pattern)

classDiagram
    direction TB
    class PricingRule { <> +computeFee(Vehicle, LocalDateTime, LocalDateTime)* BigDecimal }
    class HourlyPricingRule { +computeFee() BigDecimal }
    class EBikeFlatPricingRule { +computeFee() BigDecimal }
    class DeliveryVanTimeWindowRule { +computeFee() BigDecimal }
    PricingRule <|.. HourlyPricingRule
    PricingRule <|.. EBikeFlatPricingRule
    PricingRule <|.. DeliveryVanTimeWindowRule

    class Pass { <> +isValid(LocalDateTime)* boolean; +applyDiscount(BigDecimal)* BigDecimal }
    class MonthlyPass { -HolderRole role; +applyDiscount() BigDecimal }
    class OneDayPass { -LocalDateTime expiresAt; +applyDiscount() BigDecimal }
    Pass <|.. MonthlyPass
    Pass <|.. OneDayPass

    class Vehicle { <> #PricingRule pricingRule; +computeFee() BigDecimal }
    Vehicle --> PricingRule : Strategy Pattern
    Vehicle <|-- EBike
    Vehicle <|-- DeliveryVan
    Vehicle <|-- Car
    Vehicle <|-- TwoWheeler
